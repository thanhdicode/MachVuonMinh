# DESIGN SYSTEM V2

## Creative thesis
“Revolutionary print becomes a living machine.”

Not:
- beige PowerPoint
- propaganda-poster cosplay
- government portal
- neon AI SaaS
- generic Awwwards clone

## Palette
--paper-light: #F3E8D0
--paper:       #E7D8B8
--paper-deep:  #D3BE95
--ink:         #171512
--ink-soft:    #302B25
--red:         #B51F2A
--red-hot:     #D12430
--red-dark:    #661419
--brass:       #B48B43
--oxide:       #7C4635
--steel:       #6D706C

Scene rhythm:
00 paper + ink + red thread
01 warm paper + earth
02 ink-black + steel + red-hot
03 cool neutral + red signal
04 red-dark/near-black + cream particles
05 graphite + ivory core + red cage
06 bright paper + red map + brass evidence nodes
07 dark chamber + tactile lever tokens
08 bright paper + red adaptive loop

## Typography
ONLY TWO global families:
- Be Vietnam Pro: title/body
- IBM Plex Mono: labels/source/chapter codes

No serif paragraphs.
No 4-font mixture.
No all-caps body copy.

Hero: clamp(4rem, 10vw, 10rem)
Scene headline: 52–84px desktop
Body: 17–20px
Labels: 11–12px mono

Copy limits:
- hero: max 2 title lines
- scene headline: max 2 lines
- scene body: max 3 lines / ~40 words
- evidence detail: max 55 words

## Layout rhythm
Do not center every scene.

Alternate:
A. text left 34% / world right 66%
B. full-bleed world + edge annotations
C. tension split: LLSX left / QHSX right / physical core center

## No-card rule
Core narrative cards are forbidden.
Cards only allowed in secondary source/settings drawers.

No:
- chapter card
- feature-card grid
- checkbox-card grid
- white rectangle floating in empty beige space

## Print/material language
- subtle animated paper grain
- 1–2% print-registration offset during transitions
- occasional halftone/dither
- red ink masks
- measurement lines / stamped chapter code

Keep texture opacity low.

## Navigation
Remove permanent top-right button row and left chapter rail.

New:
top-left small wordmark
top-right tiny `00 / 08` + menu glyph
progress is represented by the red thread itself

Menu/source reveal uses ink-bleed transition.

## 3D materials
LLSX:
- warm ivory deforming inner material
- pulse
- slight organic turbulence

QHSX:
- segmented red painted-metal / smoked translucent cage
- gates / plates / joints

Historical scenes:
simple geometry + premium light > weak illustration.

## QA
Every screenshot needs:
- one dominant visual
- clear eye path
- no giant useless empty beige region
- no slide-deck composition
- red thread visibly meaningful
