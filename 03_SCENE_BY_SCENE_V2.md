## 05 — DIALECTIC LAB
This is the hero feature.

Full-screen 3D core at center (~55% viewport).

Left edge: 5 compact micro sliders:
Công nghệ / Dữ liệu / Kỹ năng / Hạ tầng / Tự động hóa

Right edge: 3 compact micro sliders:
Sở hữu / Tổ chức–quản lý / Phân phối

No dashboard cards.

Inner ivory core = LLSX.
Outer segmented red cage = QHSX.

States:

FIT
- smooth flow
- cage breathes with core

STRAIN
- core touches shell
- plates bend
- warm warning signal

CONTRADICTION
- energy pools at blocked gates
- plates misalign
- brief camera impulse
- short typography disturbance

RECONFIGURATION
- cage plates detach
- orbit
- snap into new topology
- flow stabilizes

Bottom copy: one status + one sentence.

Example:
`MÂU THUẪN`
`Năng lực sản xuất đang biến đổi nhanh hơn mức thích ứng của quan hệ sản xuất.`

Permanent:
`Mô phỏng khái niệm — không phải mô hình định lượng.`

Tiny presets:
CÂN BẰNG / LLSX VƯỢT TRƯỚC / QHSX CỨNG / TÁI CẤU TRÚC
