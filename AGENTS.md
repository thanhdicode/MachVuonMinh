# Project instructions

Read `00_NORTH_STAR.md` through `07_MASTER_PROMPT_V2.md` in numbered order before implementing the experience. `06_TECH_ARCHITECTURE_V2.md` defines the stack and performance targets.

The red thread is the persistent visual idea. Each effect must serve a scene's meaning in `04_MOTION_AND_EFFECT_MAP.md`. Use the project skills in `.agents/skills/` only when the task calls for them; use `.studio/frontendmaxxing/` for reference, not as a source of indiscriminate effects.

Before designing a new scene, record 2–3 distinct visual directions and choose one against `.studio/ART-DIRECTION.md`. Record external assets and their verified usage rights in `.studio/ASSET-REGISTRY.md`. Keep implementation within one WebGL context, follow the DPR and mobile limits in `06_TECH_ARCHITECTURE_V2.md`, and build before reporting completion.
