# MẠCH VƯƠN MÌNH V2 — THE RED THREAD / DIALECTIC MACHINE

## Reject the current design direction
Do not preserve the centered giant-title + empty beige + floating-card composition.
Do not keep the permanent left chapter rail, top-right toolbar, generic chapter cards, checkbox challenge cards, or weak flat illustrations.
Preserve only validated content, useful logic, accessibility and performance infrastructure.

## New governing idea: THE RED THREAD
One continuous red thread travels through the whole experience.

It becomes:
- a furrow in soil
- a drive belt in mechanization
- a signal path in automation
- a fiber/data stream in the digital era
- the pulse inside the Dialectic Lab
- a network path across Vietnam
- the adaptive loop in the finale

Visual metaphor:
- LLSX = energy/pulse + expanding inner productive core
- QHSX = gates/rings/cages/structures around it
- fit = smooth flow
- mismatch = pressure, strain, blocked flow, cage deformation
- adaptation = structure reconfiguration and restored flow

The project is not a website made of sections. It is a continuous cinematic exhibition:
museum installation × interactive documentary × WebGL experiment.

Guided demo target: 3–4 minutes.
