# Studio workspace

The local `frontendmaxxing/` reference vault is a shallow clone at commit `f5260d2` and is ignored by Git to avoid copying thousands of third-party files into this project. Restore it with:

```powershell
git clone --depth 1 https://github.com/sirdath/frontendmaxxing.git .studio/frontendmaxxing
```

Start with `ART-DIRECTION.md`, then `3D-STUDIO.md`. `ASSET-REGISTRY.md` tracks asset rights; `SHADER-CATALOG.md` and `EFFECT-RECIPES.md` are design catalogs, not claims of implemented effects.
